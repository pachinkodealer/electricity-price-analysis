# Power BI dataset — electricity price analysis

Three CSVs, all generated by `build_powerbi_data.py` from public FRED data (BLS, EIA).
Re-run that script anytime to refresh with the latest month.

## Files

| File | Shape | Use it for |
|---|---|---|
| `electricity_monthly.csv` | Wide, 1 row / month (1978–present) | Line charts, the main model table |
| `electricity_long.csv` | Tidy long (date, metric, unit, value) | One line chart with a metric slicer |
| `key_metrics.csv` | 7 rows (metric, value, unit) | KPI card visuals |

## `electricity_monthly.csv` columns

| Column | Meaning | Unit |
|---|---|---|
| `date` | Month (first of month) | date |
| `elec_price_usd_per_kwh` | Avg US retail electricity price | $/kWh |
| `cpi_index` | Consumer Price Index (overall inflation) | index |
| `gas_price_usd_per_mmbtu` | Henry Hub natural gas spot | $/MMBtu |
| `elec_index_jan2020` | Electricity price, Jan 2020 = 100 | index |
| `gas_index_jan2020` | Gas price, Jan 2020 = 100 | index |
| `gas_index_jan2020_12mo_avg` | Gas index, 12-month average (smoothed) | index |
| `elec_change_6yr_pct` | Electricity % change vs. 6 years prior | % |
| `cpi_change_6yr_pct` | CPI % change vs. 6 years prior | % |
| `elec_yoy_pct` | Electricity year-over-year change | % |
| `gas_yoy_pct` | Gas year-over-year change | % |
| `cpi_yoy_pct` | CPI year-over-year change | % |
| `gas_yoy_lag6` | Gas YoY, shifted 6 months (the lag that best predicts electricity) | % |
| `model_predicted_elec_yoy_pct` | Electricity inflation the 2-factor model *expects* | % |
| `residual_unexplained_pct` | Actual minus expected = inflation **not** explained by fuel or CPI | pct pts |
| `era` | Pre-2010 / Shale decade (2010-2019) / Demand era (2020+) | category |

## How to import

1. Power BI Desktop → **Get Data → Text/CSV** → pick each file → **Load**.
2. On `date`: Data view → set **Data type = Date**. (Mark `electricity_monthly` as the date table if you add a calendar.)
3. No relationships needed if you use one table per visual. To slice everything by `era`/date together, relate tables on `date`.

## Suggested visuals (rebuilds your three charts, interactive)

1. **KPI header row** — `key_metrics.csv`, one **Card** per row (or a **Multi-row card**). Put "+47.8% since 2020", "gas −65%", "+19% since gas peak", "2.6 pts/yr unexplained" across the top.
2. **The ratchet** (headline) — **Line chart**, Axis = `date`, Values = `elec_index_jan2020` and `gas_index_jan2020_12mo_avg`. Add a constant line at 100. Title: "Gas fell back. Electricity didn't."
3. **Electricity vs. inflation** — **Line chart**, Axis = `date`, Values = `elec_change_6yr_pct` and `cpi_change_6yr_pct`. Filter to 1985+.
4. **The unexplained gap** — **Column/Area chart**, Axis = `date`, Value = `residual_unexplained_pct`, color by `era`. Add a constant line at 0. This is the "datacenter era" money shot.
5. **Slicers** — a `date` range slicer and an `era` slicer wired to visuals 2–4 so viewers can explore.

> Tip: for a single flexible chart, use `electricity_long.csv` with `metric` on a slicer and `value` on the Y axis — viewers pick which series to see.
